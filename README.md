## 🚀 Featured Polyglot Projects

Production-grade utilities and systems libraries engineered across multiple programming languages:

<table>
<tr>
<td width="50%">

### ⚡ [`hyper-probe`](https://github.com/IsmeetPandey/hyper-probe)
**High-precision TCP & HTTP latency probe with percentile distribution (P50/P90/P99) and jitter analysis.**

- Built with Rust and the \`tokio\` asynchronous networking runtime.
- Sub-millisecond timing with dynamic color-coded ANSI terminal telemetry.

**Stack:** \`Rust\` · \`Tokio\` · \`Clap\` · \`Systems Networking\`

</td>
<td width="50%">

### 🛡️ [`goguard-proxy`](https://github.com/IsmeetPandey/goguard-proxy)
**High-performance HTTP reverse proxy with adaptive token-bucket rate limiting and Prometheus metrics.**

- Lock-minimized per-IP rate limiting supporting burst thresholds.
- Zero-allocation routing on fast paths with native \`/_goguard/metrics\`.

**Stack:** \`Go\` · \`Reverse Proxy\` · \`Concurrency\` · \`Prometheus\`

</td>
</tr>

<tr>
<td width="50%">

### 🟦 [`mcp-toolkit-ts`](https://github.com/IsmeetPandey/mcp-toolkit-ts)
**Production-grade Model Context Protocol (MCP) server library for autonomous AI agents.**

- Strongly-typed tool registry with auto-generated JSON Schema manifests.
- Seamless compatibility with Claude Desktop, Cursor, and agent harnesses.

**Stack:** \`TypeScript\` · \`MCP\` · \`AI Agents\` · \`Node.js\`

</td>
<td width="50%">

### ⚙️ [`fast-ring-cpp`](https://github.com/IsmeetPandey/fast-ring-cpp)
**Cache-line aligned, wait-free Single-Producer Single-Consumer (SPSC) ring buffer in modern C++20.**

- Zero mutexes or CAS loops on critical execution path.
- Hardware interference boundary padding to prevent cache false-sharing.

**Stack:** \`C++20\` · \`Lock-Free\` · \`Low Latency\` · \`CMake\`

</td>
</tr>

<tr>
<td width="50%">

### 🏎️ [`nano-kv-c`](https://github.com/IsmeetPandey/nano-kv-c)
**Minimalist append-only embedded key-value storage engine in ANSI C99 with CRC32 integrity.**

- Log-structured sequential write persistence with in-memory hash indexing.
- Embedded data validation rejecting corrupted blocks automatically.

**Stack:** \`C99\` · \`Storage Engine\` · \`CRC32\` · \`Embedded Systems\`

</td>
<td width="50%">

### ☕ [`resilience-mesh-java`](https://github.com/IsmeetPandey/resilience-mesh-java)
**Zero-dependency fault-tolerance circuit breaker library for modern Java 21+.**

- Thread-safe state machine (CLOSED, OPEN, HALF-OPEN) with atomic references.
- Engineered for non-blocking execution with Project Loom Virtual Threads.

**Stack:** \`Java 21\` · \`Virtual Threads\` · \`Concurrency\` · \`JUnit 5\`

</td>
</tr>

<tr>
<td width="50%">

### 🐚 [`quick-env-sh`](https://github.com/IsmeetPandey/quick-env-sh)
**Idempotent, zero-dependency developer environment bootstrapper and workspace synchronizer.**

- POSIX-compliant scripting across macOS, Ubuntu, Debian, Alpine, and WSL.
- Automated OS detection, modular package deployment, and drift prevention.

**Stack:** \`Shell / Bash\` · \`Automation\` · \`DevOps\` · \`Linux/macOS\`

</td>
<td width="50%">

### 🧩 [`MCP-Surface`](https://github.com/IsmeetPandey/MCP-Surface)
