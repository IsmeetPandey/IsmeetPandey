### Selected Engineering Projects

#### 1. Systems & Low-Latency Performance
- [**`hyper-probe`**](https://github.com/IsmeetPandey/hyper-probe) *(Rust)* — High-precision concurrent TCP & HTTP latency probe with percentile distributions (P50/P90/P99), jitter variance analysis, and ANSI terminal telemetry.
- [**`fast-ring-cpp`**](https://github.com/IsmeetPandey/fast-ring-cpp) *(C++20)* — Cache-line aligned, wait-free Single-Producer Single-Consumer (SPSC) ring buffer with hardware interference padding to eliminate CPU cache false sharing.
- [**`nano-kv-c`**](https://github.com/IsmeetPandey/nano-kv-c) *(C99)* — Minimalist, embeddable append-only key-value storage engine featuring sequential write persistence and inline CRC32 block integrity validation.

#### 2. Cloud, Networking & Resilience
- [**`goguard-proxy`**](https://github.com/IsmeetPandey/goguard-proxy) *(Go)* — High-performance reverse proxy featuring atomic per-IP token-bucket rate limiting, zero heap allocations on fast paths, and native Prometheus metrics.
- [**`resilience-mesh-java`**](https://github.com/IsmeetPandey/resilience-mesh-java) *(Java 21)* — Zero-dependency fault-tolerance circuit breaker and retry orchestrator architected for Project Loom Virtual Threads.
- [**`quick-env-sh`**](https://github.com/IsmeetPandey/quick-env-sh) *(POSIX Shell)* — Idempotent, zero-dependency developer workspace bootstrapper with automated OS detection for macOS, Linux, and WSL.

#### 3. AI Agent Infrastructure & Protocols
- [**`mcp-toolkit-ts`**](https://github.com/IsmeetPandey/mcp-toolkit-ts) *(TypeScript)* — Production Model Context Protocol (MCP) server toolkit for autonomous AI agents with typed runtime schema generation and guardrails.
- [**`MCP-Surface`**](https://github.com/IsmeetPandey/MCP-Surface) *(Python)* — Offline linting CLI for Model Context Protocol tool manifests, schemas, and descriptions to prevent agent tool-call failures.
- [**`APIGuard`**](https://github.com/IsmeetPandey/APIGuard) *(Python)* — Preflight contract verification CLI to detect breaking changes in OpenAPI specifications before deployment.
